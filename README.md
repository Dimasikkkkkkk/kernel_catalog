# kernel_catalog

Публичный JSON-каталог комплектующих для приложения [kernel_app](https://github.com/Dimasikkkkkkk/kernel_app) (приватный репозиторий).

Обновляется автоматически из CI `kernel_app` (workflow **Update catalog**).
